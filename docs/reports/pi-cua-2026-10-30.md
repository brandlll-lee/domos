# Pi 桌面工具与图片验收

脱敏基线保存在 `packages/agent/test/fixtures/cua-contracts.json` 的 `piObservation`。任务 9586 耗时 79.733 秒，含 9 次模型响应和 8 次工具调用。8 次调用均经 codemode。脚本用 `text(result.content)` 把截图转成文字，输出超过十万 token 后截断。该观察传给模型的图片块为零。另一次脚本因 `setTimeout is not defined` 失败。记录不证明发生了语音误触。

Pi 统一通过原生 MCP 直接声明产品工具。子进程加载原生 tool-search、Domos 扩展和原生 MCP。tool_search 在会话开始时启用，也可发现配置为 codemode 或 deferred 的外部 MCP 工具。此配置适用于全部 Pi 产品会话，不按桌面能力分支。账户文件与外部 MCP 配置保留。

共享指引要求直接调用桌面工具。输入和提交按键绑定同一窗口与控件。控件变化后先观察。界面等待使用桌面条件检查。原生批次、脚本、权限、停止和未知结果保护继续由现有服务负责。

协议回归先在旧配置下复现 codemode 仍出现在原生工具目录，再验证直接工具、tool_search 和两个外部 MCP 目录均可用。工具发现警告为空。共享网关回归检查图片块与原生结构化结果保留。

Windows 在线验收使用 Pi 1.4.0、deepseek/deepseek-flash 和 Cua 0.37.0。模型直接调用一次观察工具。Cua 读取专用 Chrome 测试窗口的真实截图。模型正确返回只在图片中提供的随机文字、结构化标记、坐标、`verified: false` 和记忆查询回执。工具记录没有 codemode。该测试通过，运行耗时 9.25 秒。其模型响应轮数未记录。

原生桌面输入 E2E 通过，运行耗时 10.1 秒。它在独立测试窗口执行输入与点击，并读回真实控件结果。此测试不调用模型。在线图片验收与原生输入验收属于两项独立检查，不等于重新执行历史聊天发信任务。

`pnpm test` 最终通过 361 项，跳过 40 项。首次分组运行有一项接管释放检查超时；该项单独重跑及完整重跑均通过。`pnpm typecheck` 通过。`pnpm lint` 保留 8 项已有警告。桌面端构建通过。运行目录中的 Pi 扩展与 worker 文件散列和源码一致。打包服务包含共享桌面指引。未验证其他操作系统及其他 Harness 的在线模型。两次任务条件不同，不据此报告速度或成功率提升。

依据已核对已安装 Pi 1.4.0 源码及官方 [MCP](https://pi.dev/docs/latest/mcp)、[Codemode](https://pi.dev/docs/latest/codemode) 文档。
