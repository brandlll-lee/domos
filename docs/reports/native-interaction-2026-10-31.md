# 原生桌面与消息验收

## 桌面

桌面执行使用 Cua 0.37.0 原生宿主和 MCP stdio。宿主通过 SDK 私有生命周期启动。工具目录、参数、结果及取消信号直接转发。桌面查看器连接同一个宿主。光标由原生会话持有，使用 signature_arc、steady 和原生减弱动态规则。

安装先查已有程序和匹配版本。缺失时下载对应版本官方发布包，核对发布 SHA-256。桌面构建把完整原生运行文件放入工作进程目录。

窗口描边、Domos 覆盖窗口、自制轨迹、效果订阅和效果查询已删除。Agent 工具目录不提供固定浏览器睡眠。桌面指引使用原生条件等待。

Windows 实际验收：专用测试窗口通过中文前台输入、控件点击、批次、条件检查和脚本输入。窗口结果读回正确。原生光标读回 enabled=true、实际位置、会话和 signature_arc/steady。E2E 约 14.5 秒，不调用模型。

共享执行、取消、接管和桌面查看回归共 38 项通过。Typecheck 通过。Lint 保留八项原有警告。

脱敏基线为任务 10626：188.5 秒、27 次模型响应、27 次工具、11 张模型图片。它包含三次浏览器固定等待。此次验收没有重跑在线音乐任务，不能报告模型耗时或任务成功率改善。macOS、Linux 尚未实际验收。
