# 共享电脑调用验收

## 失败基线

任务 9843 使用 Pi 与 DeepSeek Flash。用户要求播放指定歌手的指定歌曲。任务在 161.074 秒后停止，未核验目标歌曲播放。记录有 15 次模型响应、15 次工具调用和 6 张发模图片。三次 PowerShell 调用的 Work 接收耗时合计 29.324 秒。应用列表的 JSON 副本被截断，读取副本也无法解析。失败批次已有成功收尾观察，但后续动作仍被统一错误屏障阻断。脱敏样本保存在 `packages/agent/test/fixtures/cua-contracts.json`。

## 当前实现

- 共享电脑模块处理参数验证、审批、接管和证据。原生调用直接进入该模块。其他产品工具继续使用 ToolTask。
- 每次原生电脑调用先保存意图，再保存完整结果。已完成请求复用结果。未知请求不重放。停止继续撤销运行并终止原生 Harness 进程树。
- 桌面协议转发原生 MCP 结果，保留结构、图片和元数据。Cua 继续拥有会话、输入和原生窗口验证。
- 大结果按完整记录生成有效 JSON 预览。只读 query_result 可查询完整记录。它不重跑工具。
- 失败批次的成功收尾观察参与恢复判断。未知动作仍需观察。脚本、批次和直接动作共用恢复规则。
- 所有 Harness 共用目录与电脑指引。目录开放原生动作，隐藏维护工具，并在专用浏览器启用时隐藏重复浏览器工具。

## 已取得的证据

真实 Windows 应用目录包含 275 项。一次原生 list_apps 调用后，query_result 找到了网易云音乐的启动路径。连接及首次调用合计约 644 毫秒，查询约 3 毫秒。该探针没有扫盘，也没有再次调用原生工具。此数值属于当前只读探针，不能与旧任务总时长直接比较。

Pi 与 OpenCode 的真实模型图片测试均通过，合计运行 22.92 秒。模型通过 Cua 截图读取随机文字，并返回结构化标记、坐标和记忆回执。该测试验证图像与元数据传递，不验证完整播放器任务的成功率。

依据已核对安装的 Cua 0.37.0 与 Pi 1.4.0，以及官方 [Cua SDK](https://cua.ai/docs/cua-driver/guides/use-the-sdk) 和 [Pi MCP](https://pi.dev/docs/latest/mcp) 文档。

## 回归与边界

全量单元及协议测试通过：362 项，40 项按环境跳过。类型检查通过。Lint 通过，保留 8 项已有警告。

Windows 原生输入回归通过，耗时 8.3 秒。测试在独立窗口输入中文并读回真实页面，覆盖原生直接动作、批次、脚本、截图与坐标。Cua 会接受只有 PID 的批次，因此 Domos 保留批次窗口身份校验。恢复生成的观察也保留在返回内容中。

本轮在线模型验收仅覆盖 Pi 与 OpenCode。Codex、Claude 和 ACP 由协议回归覆盖。本轮未执行完整播放器任务，未验证 Linux、macOS 或总体成功率改善。

桌面构建通过。桌面包与工作电脑镜像均包含共享结果查询模块。
