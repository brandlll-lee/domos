# 渐进式上手与电脑归属

状态：已采用。

桌面先启动回环后台，再进入主界面。模型和 Docker 按需配置。桌面通过父子进程通道获取本地设备会话。会话写入对应实例的 HttpOnly Cookie。网页只调用固定 IPC。远程实例仍需独立配对。自托管不要求云账号。

Bot 创建只要求名字。模型、职责和电脑均可稍后配置。缺少模型时，发送操作打开模型设置。草稿留在输入框。用户确认后再发送。

Pi 会话文档 `domos.computers` 的版本为 1。文档保存电脑记录、默认电脑和 Bot 绑定。配置与实际探测结果共同决定能力。界面、提示词和执行环境读取同一目录。Pi 继续管理工具和执行环境。

新 Bot 默认不分配电脑。本机必须先获得明确授权。已授权的电脑可设为共享默认值。多个 Bot 可共用电脑。工作目录按 Bot 分开。无绑定时，Pi 禁用命令和工作区工具。环境解析再次校验绑定和授权。

绑定修改检查版本、运行任务和文件传输。执行期间禁止切换或撤销目标。定时任务执行相同检查。目标不可用时明确失败。系统不选择替代电脑。切换目标不迁移工作文件。附件记录原目标。

电脑生命周期由实例设置管理。Bot 详情只管理归属。当前支持本机命令与文件、本地 Docker、SSH Docker，以及已有控制端。真实桌面点击、SPACE 和 sbx 需独立接入。云注册、租户隔离和云端分配需独立交付。

升级时，已有电脑标记触发迁移。旧 Bot 保留原目标和权限。目录保存旧附件的目标。目录初始化先于 Pi 恢复任务。后续启动使用目录内的绑定。升级前先备份。回滚时恢复对应代码和数据。

加密备份保存目录、绑定、权限和本机工作文件。Docker 工作卷逐台归档。恢复时创建新卷，并保留目录标识。已有控制端备份继续使用原归档格式。
