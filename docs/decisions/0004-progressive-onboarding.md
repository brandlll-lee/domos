# 渐进式上手与电脑归属

状态：已采用。

桌面首次启动先选择本机运行或连接已有 Domos。本机准备页显示后台报告的进度。后台与本机设备会话就绪后，桌面打开工作区。失败时保留选择并提供重试。会话写入对应后台的 HttpOnly Cookie。网页只调用固定 IPC。远程连接仍需独立配对。自托管不要求云账号。

首次配置依次完成电脑授权、AI 服务选择、原生登录、模型保存和就绪确认。模型保存成功后才显示就绪页。用户可跳过引导并进入工作区。跳过状态保存在当前客户端的电脑视图中。新 Bot 沿用共享电脑。模型账号失效后，发送操作打开模型设置。草稿留在输入框。用户确认后再发送。

启动与入门页面由 `packages/ui/src/web/startup/` 提供。桌面准备、网页配对和首次配置共用 `StartupPages`。本地 Spec03 预览直接引用产品组件。页面使用现有主题、字体、角色、控件和窗口标题栏。

欢迎页显示五位伙伴。准备页使用 16:9 电脑、单 Bot 近景到远景和底部透明加载层。远程与配对页显示 Bot 和电脑之间的双向传递。登录与模型页将电脑替换为实际 Harness 标志。就绪页复用角色爆炸入场和前景遮挡。动态效果遵循减少动态设置。主题样式由共享 tokens 生成，Electron 从外部样式表读取，网页初始化使用相同内容。

配对码使用现有交换接口。配对页读取公开电脑标识与当前访问地址。设备访问记录默认名为“我的设备”。桌面连接默认名为“我的 Domos”，已有地址复用保存的名称。已保存连接、Docker 选择和取消准备位于辅助入口。服务准备、登录和保存均使用真实状态。

登录、安装和连接失败保留原生操作入口。模型保存失败保留当前选择并允许重试。稍后设置按电脑保存。已有授权与模型配置直接进入工作区。电脑切换继续保留会话分区、草稿和阅读位置。

Pi 会话文档 `domos.computers` 的版本为 1。文档保存电脑记录、默认电脑和 Bot 绑定。配置与实际探测结果共同决定能力。界面、提示词和执行环境读取同一目录。Pi 继续管理工具和执行环境。

电脑记录保存共享或独立归属。共享电脑按后台复用。独立电脑按 Bot 复用容器和工作卷。重复准备请求复用记录。失败时保留旧绑定。准备完成后才修改绑定。已停止的托管电脑在执行任务或传输文件前启动。系统以 Docker 探测结果确认状态。本机必须获得明确授权。无绑定时，Pi 禁用命令和工作区工具。环境解析再次校验绑定和授权。

绑定修改检查版本、运行任务和文件传输。执行期间禁止切换或撤销目标。定时任务执行相同检查。目标不可用时明确失败。系统不选择替代电脑。切换目标不迁移工作文件。附件记录原目标。

Bot 电脑页完成准备、授权和绑定。高级管理收纳镜像、SSH、路径、停止和重建。当前支持本机命令与文件、本地 Docker、SSH Docker，以及已有控制端。真实桌面点击、SPACE 和 sbx 需独立接入。云注册、租户隔离和云端分配需独立交付。

升级时，已有电脑标记触发迁移。旧 Bot 保留原目标和权限。目录保存旧附件的目标。目录初始化先于 Pi 恢复任务。后续启动使用目录内的绑定。升级前先备份。回滚时恢复对应代码和数据。

加密备份保存目录、绑定、权限和本机工作文件。Docker 工作卷逐台归档。恢复时创建新卷，并保留目录标识。已有控制端备份继续使用原归档格式。
