# 工作界面与设置边界

状态：已采用。

窗口栏承载品牌、创建入口和应用菜单。左侧外壳竖列承载会话、工作电脑与用量入口，底部承载全局设置。聊天顶部栏承载当前 Bot 的上下文圆环、模型切换、电脑与详情；圆环以环形进度表示上下文占用，开启独立浮层查看分布与压缩。用量独占整个会话面，按时间段展示成本、用量、构成与明细；它不依赖选中 Bot 的右侧面板。桌面使用系统窗口按钮和受限 IPC。窗口颜色读取共享主题。网页不显示窗口操作。窄屏隐藏外壳竖列，设置与用量回到联系人面板底部。

全局设置主导航为通用和模型。通用管理主题、其他设备访问和数据备份。配对码、已授权访问和撤销权限使用同一流程。电脑高级管理通过明确入口打开。桌面菜单管理其他 Domos 的连接。Bot 详情管理身份、所选模型、工作环境和工作配置。功能组件继续调用现有 Hooks 与 RPC。布局组件只接收内容与回调。

窗口栏与左侧留白共用最深的外壳底色，左栏、聊天区与详情合成同一会话面、统一使用聊天区底色，以内圆角嵌入外壳：左边与顶边露出外壳，边缘只留一条极细的线，左右面板之间同样以细线分隔。标题与内容、同组多行使用淡细线，组间使用留白。外壳、内容、控件、悬停和选中状态读取共享主题变量。字阶与控件尺寸由共享 UI 定义，页面只负责布局。所有选择控件复用同一组件与菜单样式。

设置使用左侧导航、右侧固定标题与独立滚动内容。窄屏导航同步切换视觉方向和键盘方向。全局品牌使用同一组件。Bot 目录保存可选的创建时间，空会话在顶部显示该时间。字段缺失时保持空白。

联系人目录统一提供忙碌状态和消息预览。预览读取 Pi 已提交的消息，空会话使用真实职责。目录按页读取近期记录，不保存第二份历史。列表展示与搜索使用同一预览，前端只订阅当前会话。

左右面板共享指针和键盘调宽行为。布局状态使用 domos:layout:v1。拖动结束后保存用户宽度。视口约束只改变展示宽度。存储不可用时继续保留本次交互。窄屏使用同一面板内容和 Dialog 焦点管理。

关闭详情暂停订阅。已编辑的表单保留在内存中。切换 Bot 或刷新页面会重建详情。聊天草稿沿用原持久化机制。全局设置切换分类保留表单；关闭时检查未保存的模型配置，并等待正在执行的请求。

创建时间为目录的可选字段，与现有文档版本兼容。旧代码继续读取其他字段。权限校验和执行目标仍由后端决定。
