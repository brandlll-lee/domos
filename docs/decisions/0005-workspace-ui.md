# 工作界面与设置边界

状态：已采用。

顶部工具栏承载当前 Bot、创建入口和全局设置。桌面使用系统窗口按钮和受限 IPC。窗口颜色读取共享主题。网页不显示窗口操作。

全局设置管理外观、模型连接、电脑目录、设备和实例。Bot 详情管理身份、所选模型、电脑绑定和工作配置。功能组件继续调用现有 Hooks 与 RPC。布局组件只接收内容与回调。

区域通过底色、留白和淡细线区分。主区域之间保留边界。同组多行使用缩进分隔线，组间使用留白。外壳、内容、控件、悬停和选中状态读取共享主题变量。字阶与控件尺寸由共享 UI 定义，页面只负责布局。

设置使用左侧导航、右侧固定标题与独立滚动内容。窄屏导航同步切换视觉方向和键盘方向。全局品牌使用同一组件，空会话使用当前 Bot 的头像与名字。

联系人目录统一提供忙碌状态和消息预览。预览读取 Pi 已提交的消息，空会话使用真实职责。目录按页读取近期记录，不保存第二份历史。列表展示与搜索使用同一预览，前端只订阅当前会话。

左右面板共享指针和键盘调宽行为。布局状态使用 domos:layout:v1。拖动结束后保存用户宽度。视口约束只改变展示宽度。存储不可用时继续保留本次交互。窄屏使用同一面板内容和 Dialog 焦点管理。

关闭详情暂停订阅。已编辑的表单保留在内存中。切换 Bot 或刷新页面会重建详情。聊天草稿沿用原持久化机制。全局设置切换分类保留表单；关闭时检查未保存的实例和模型配置，并等待正在执行的请求。

本次不改变业务数据格式。回滚界面提交后，旧代码忽略布局偏好。权限校验和执行目标仍由后端决定。
