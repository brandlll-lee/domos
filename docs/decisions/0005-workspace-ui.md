# 工作界面与设置边界

状态：已采用。

工作区使用三栏布局。左栏顶部显示当前电脑选择器，再提供搜索和创建 Bot，下方显示联系人。选择器列出已保存连接，并提供连接其他电脑和管理连接。收起侧栏保留电脑图标入口。左栏底部显示用户菜单和应用连接。用户菜单向上展开，提供设置、用量和桌面操作。用户入口使用中性用户图标。中栏顶部显示居中的 Bot 身份入口。56px 动画头像使用透明背景，前置覆盖下方姓名框上边缘 10px。空闲姓名框高 30px，内容水平与垂直居中，使用小圆角、细边缘和轻阴影，亮色使用白色，暗色使用中性灰弹层色。12px Harness 图标位于 14px 昵称前，间隔 4px。团队使用成员组合头像与团队名。工作时姓名框增加一行 12px 次级状态文字，宽度固定并省略长文字。停止和用户等待优先于工具动作。工具完成后清除旧动作。顶部与 Work 共用现有执行记录的活动判定。团队显示当前成员，多个成员工作时显示人数。共享头像通过已有脸部坐标佩戴无线耳机并展示电脑，所有角色使用同一套装饰。新执行触发一次短促变身，等待时停止打字，完成后收起装饰。断线隐藏活动，同一执行重连不重播变身。减少动态效果时直接切换装饰。整个入口点击后打开详情。聊天独立预留工作态的最大顶部高度。模型、推理强度和上下文圆环位于右栏 Bot 页。右栏保留 Bot、Computer、Browser 和 Work 四个 Tab。宽窗口默认显示右栏，窄窗口使用覆盖式面板。用量在中栏展示，点击联系人或再次点击用量返回聊天。

全局设置主导航为通用、AI 服务和当前电脑。通用管理主题和数据备份。当前电脑管理名称、访问设备和电脑权限，容器位于高级设置。配对码、已授权访问和撤销权限使用同一流程。电脑选择器和原生菜单共用桌面连接管理。Bot 详情管理身份、所选模型、工作环境和工作配置。功能组件继续调用现有 Hooks 与 RPC。布局组件只接收内容与回调。

桌面窗口保持稳定。每个地址保留独立会话分区。连接切换准备目标内容视图，授权和连接记录保存成功后替换当前视图。取消和失败保留原工作区。替换前保存阅读锚点并卸载旧界面，关闭订阅及查看器租约。草稿、联系人、右栏和阅读位置按电脑身份隔离。阅读恢复通过现有游标读取有界历史。连接记录留在桌面主进程，网页只读取名称、标识和模式。移除连接不删除远端数据。

左栏融入窗口底板，沿用侧栏颜色。聊天与右栏共用内嵌圆角外框，外围留出 8px 底板，内部保留细分隔线和调宽入口。窄屏聊天占满窗口，面板使用原有抽屉。背景、控件、悬停和选中状态读取现有共享主题变量。字阶与控件尺寸由共享 UI 定义。身份入口复用现有动画头像和 Harness 图标。面板复用共享过渡、调宽和焦点管理。网页不显示系统窗口按钮。

控件和浮层使用接近主题背景的表面色。输入框以细边框和焦点边框区分状态，不以大块亮色强调。文本框保留内部滚动，不显示缩放手柄。原生滚动区与共享 ScrollArea 使用同一组滑块颜色。记忆、技能和定时列表以细分隔线排列。编辑表单直接放在页面或弹窗正文中，不再套装饰卡片。字段标签说明输入用途，避免重复页面标题。

桌面保留 Electron 原生窗口按钮。顶部空白区域允许拖动，控件使用 `no-drag`。Windows 和 Linux 预留右侧窗口按钮区域，macOS 预留左侧按钮区域。图片查看器也避开原生按钮。连接设置页使用独立标题栏。窗口外观读取共享主题。平台依据：[自定义标题栏](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)、[窗口交互](https://www.electronjs.org/docs/latest/tutorial/custom-window-interactions)。

设置使用左侧导航、右侧固定标题与独立滚动内容。打开全局设置时，工作面板暂时隐藏，但保留页面和连接。关闭设置后，窄屏焦点返回覆盖面板，宽屏焦点返回用户菜单入口。窄屏导航同步切换视觉方向和键盘方向。全局品牌使用同一组件。Bot 目录保存可选的创建时间，空会话在顶部显示该时间。字段缺失时保持空白。

工作区宽度通过 React `useSyncExternalStore` 读取视口，保证面板恢复时使用当前布局。提交布局时核对实际视口；尺寸已变化时结束当前快照过渡，不等待 resize 事件。设置完成关闭后才恢复工作面板。技能操作进行时，文件导入入口与其他操作同时禁用。React DOM 19.3.1 的依赖修正采用[官方错误分类](https://github.com/react/react/pull/38034)，只忽略隐藏页面和视口变化造成的预期动画取消，继续报告实际错误。

拖宽验收通过 Chrome Performance 的线程 CPU 计时核对布局与样式计算，每帧平均不超过一个 60Hz 帧预算。帧间隔与同次空闲基线同时记录。共享 CI 的调度间隔不能作为布局耗时。

居中弹窗共用固定尺寸、边框、圆角和虚化遮罩。暗色背景沿用工作区 canvas，浅色保留各自现有表面。尺寸沿用设置窗口令牌，并受视口约束。标题与底部操作固定，正文独立滚动。顶部 Bot 身份入口、上下文圆环和模型设置使用同一 Harness 图标，读取实际引擎身份。

联系人目录按 Bot 组织私聊。Bot 行显示头像、名称和上次会话摘要，点击主体打开该会话。箭头单独控制展开。当前会话可见时只选中子行，否则选中 Bot 行。子行左侧显示状态，中间显示标题，右侧显示时间。工作、排队、等待、失败和未读会话先显示。默认显示三条空闲会话，包含当前空闲会话。其余会话可在组内展开。聊天顶部的当前会话入口打开共享管理弹窗，支持新建、搜索、分页和归档。收起侧栏使用头像菜单。归档隐藏会话并保留历史。标题取首条非空输入，手动命名后保留。草稿、阅读位置和模型配置按电脑与会话隔离。目录提供轻量状态，前端只订阅当前会话全文。

左右面板共享指针和键盘调宽行为。布局状态使用 domos:layout:v1。拖动时每帧只应用最新宽度，宽度不变时不更新状态。正文、图片、表格和输入区随实际宽度实时排版。消息继续复用缓存和分页。侧栏开合一次提交最终布局，再用原生 transform 动画连接聊天区、头像和按钮的位置。收起的文字保留原位置并渐隐。快速反向切换从当前显示位置接续。动画使用现有 220ms 令牌。中途开始拖动时，读取已显示的宽度并计入页面缩放。其他面板开关继续使用 React ViewTransition。拖动期间不创建聊天区快照。拖动结束后保存用户宽度。视口约束只改变展示宽度。存储不可用时继续保留本次交互。窄屏使用同一面板内容和 Dialog 焦点管理。弹窗、菜单和浮层共用透明度与缩放过渡，由 Base UI 在退场完成后卸载。关闭期间停用交互，正文保留到退场完成。减少动态效果时直接切换。实现依据：[React ViewTransition](https://react.dev/reference/react/ViewTransition)、[Base UI 动画生命周期](https://base-ui.com/react/handbook/animation)、[布局开销](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing)。

联系人栏向左拖过收起阈值后，变为 96px 图标栏。头像入口使用联系人高度令牌，显示为居中的圆角正方形。选中底色使用 surface，悬停底色使用 hover，与搜索、新建按钮共用主题颜色。头像、搜索、新建和底部操作继续使用同一组件。向右拖动、双击分隔线或使用方向键可展开。搜索图标展开联系人栏并聚焦搜索。展开宽度与收起状态分别保存。收起和展开遵循减少动态效果设置。窄屏抽屉保持完整联系人列表。

详情首页按打开时读取能力摘要。资料编辑页独立读取用户资料。技能、定时和记忆保持 Work 实时订阅。各页面只展示其数据源的读取或错误状态，已有内容在刷新时保留。切换到 Computer、Browser、Work 或关闭详情会暂停工作资料订阅。已编辑的表单保留在内存中。HTTP/1 下两个默认打开的首页不应占满连接并阻塞普通请求，参见 [MDN 连接限制](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events)。切换 Bot 或刷新页面会重建详情。聊天草稿沿用原持久化机制。全局设置切换分类保留表单；关闭时检查未保存的模型配置，并等待正在执行的请求。

Harness 状态、模型目录和思考选项由每个 Bot 的共享状态持有。切换侧栏立即显示已有信息，后台检查完成后再更新。模型选择立即更新显示并关闭菜单。保存按序执行。思考选项继续可用。发送任务前等待保存完成。失败时恢复已确认的选择，并显示错误。

消息行使用实际布局高度。消息和加载气泡复用 React ViewTransition，统一插入、位移和离场。首次读取和后台更新直接展示内容。滚动位置在布局阶段校正；上翻阅读时保持锚点。输入和停止操作保持即时更新。动效使用共享时长与曲线，并遵循减少动态效果设置。

聊天历史每页最多 200 条。文件定位使用已保存的消息游标，直接读取目标附近的一页。该阅读窗口与实时更新分开，支持向前、向后翻页和返回最新。实时连接只发送变化的消息和运行字段。工具正文和内嵌图片按需读取。翻页保留阅读位置。实时更新和重新连接保留已加载的历史。Work 详情按需补齐跨页记录。面板开关的快照限定在面板内，聊天列按实际宽度排版。

创建时间为目录的可选字段，与现有文档版本兼容。旧代码继续读取其他字段。权限校验和执行目标仍由后端决定。

Work 按每次完整执行显示紧凑记录。当前执行置顶，失败和结果待核对的记录归入“需要关注”，其余记录按本地日期分组。首行显示请求的首个有效文本行；定时任务使用已有名称，纯附件输入使用文件名。次行显示原生当前活动或最终状态及耗时，历史记录另列开始时间。追加输入归入原执行，详情保留完整请求。私聊列表省略重复的 Bot 身份和模型；团队记录保留执行成员身份。列表使用透明背景和 4px 行间距。状态点标明运行、等待、失败和待核对。原生执行结束与工具失败或回执缺失分别展示。运行时提供独立的图标停止按钮。点击整行在右栏内切换到工作详情。Bot 身份与 Tab 保持固定，聊天继续可见。返回列表恢复滚动位置和来源焦点。定时任务记录复用同一详情。详情以圆形类型图标、细连接线、步骤标题、两行摘要和右侧耗时组成时间线。耗时优先使用原生报告值，其次使用已保存的起止时间，缺失时显示未知。步骤默认折叠，展开后按需读取完整工具参数、结果和证据。任务输入收纳完整请求、模型与定时信息。团队详情保留执行成员，子任务保留来源关系。问题定位展开并聚焦首个失败或待核对步骤，诊断入口保留原有记录。停止按钮与输入框调用同一接口。历史状态从现有持久记录恢复。


## 聊天交互卡片

原生提问和权限审批使用聊天卡片。单选点击即提交；多选和自由输入确认后提交。待处理卡片显示问题和操作。已处理记录显示为居中轻量事件，点击后在共享弹窗中查看问题、选项、回答和结束状态。旧记录的原文通过技术详情查看。输入区只保留消息编辑及运行控制。

共享 ComputerRuntime 保存待处理请求和最终记录。原生协议负责接收回答。原生关闭、停止及服务重启使待处理请求失效。消息 ID 在请求生命周期内保持稳定。现有增量连接更新卡片，历史继续按页读取。

接管卡片显示等待接管、控制中、已归还或已失效。查看器的实际控制租约决定控制中状态。关闭查看器释放租约，保留未完成请求。完成请求先排空输入，再交还控制权。

图片和文件复用附件组件。图片支持预览，文件支持下载。同一轮按文件 ID 合并重复交付，最终回复携带附件时不再单独展示同一份工具附件。

当前 Bot 父行保留较淡背景。当前会话子行保留选中背景。两者由当前路由派生，不增加持久化状态。父行头像与子行图标共用 36px 布局列。交互浮层在共享表面声明 no-drag，覆盖菜单空白和菜单项。
