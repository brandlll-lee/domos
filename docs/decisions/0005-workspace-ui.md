# 工作界面与设置边界

状态：已采用。

工作区使用三栏布局。左栏顶部提供搜索和创建 Bot，下方显示联系人。环境切换、用量、全局设置和桌面菜单位于左栏底部。中栏顶部只显示居中的 Bot 胶囊。动画头像在前，稍微遮住当前 Harness 图标，右侧显示昵称。点击胶囊打开 Bot 详情。模型、推理强度和上下文圆环位于右栏 Bot 页。右栏保留 Bot、Computer、Browser 和 Work 四个 Tab。宽窗口默认显示右栏，窄窗口使用覆盖式面板。用量在中栏展示，点击联系人或再次点击用量返回聊天。

全局设置主导航为通用和模型。通用管理主题、其他设备访问和数据备份。配对码、已授权访问和撤销权限使用同一流程。电脑高级管理通过明确入口打开。桌面菜单管理其他 Domos 的连接。Bot 详情管理身份、所选模型、工作环境和工作配置。功能组件继续调用现有 Hooks 与 RPC。布局组件只接收内容与回调。

三栏占满窗口，以细分隔线区分。背景、控件、悬停和选中状态读取共享主题变量。字阶与控件尺寸由共享 UI 定义。胶囊复用现有动画头像和 Harness 图标。面板复用共享过渡、调宽和焦点管理。网页不显示系统窗口按钮。

桌面保留 Electron 原生窗口按钮。顶部空白区域允许拖动，控件使用 `no-drag`。Windows 和 Linux 预留右侧窗口按钮区域，macOS 预留左侧按钮区域。图片查看器也避开原生按钮。连接设置页使用独立标题栏。窗口外观读取共享主题。平台依据：[自定义标题栏](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)、[窗口交互](https://www.electronjs.org/docs/latest/tutorial/custom-window-interactions)。

设置使用左侧导航、右侧固定标题与独立滚动内容。打开全局设置时，工作面板暂时隐藏，但保留页面和连接。关闭设置后，窄屏焦点返回覆盖面板，宽屏焦点返回设置入口。窄屏导航同步切换视觉方向和键盘方向。全局品牌使用同一组件。Bot 目录保存可选的创建时间，空会话在顶部显示该时间。字段缺失时保持空白。

居中弹窗共用固定尺寸、边框、圆角和虚化遮罩。尺寸沿用设置窗口令牌，并受视口约束。标题与底部操作固定，正文独立滚动。顶部 Bot 胶囊、上下文圆环、模型设置和 Work 使用同一 Harness 图标，读取实际引擎身份。

联系人目录统一提供忙碌状态和消息预览。预览读取 Pi 已提交的消息，空会话使用真实职责。目录按页读取近期记录，不保存第二份历史。列表展示与搜索使用同一预览，前端只订阅当前会话。

左右面板共享指针和键盘调宽行为。布局状态使用 domos:layout:v1。拖动时每帧只应用最新宽度，宽度不变时不更新状态。正文、图片、表格和输入区随实际宽度实时排版。消息继续复用缓存和分页。收起阈值触发一次共享 CSS 宽度过渡，侧栏与聊天区域同步变化。文字渐隐，头像随入口收拢。动画使用现有 220ms 令牌。中途开始拖动时，读取已显示的宽度并计入页面缩放。面板开关继续使用 React ViewTransition。拖动和吸附期间不创建聊天区快照。拖动结束后保存用户宽度。视口约束只改变展示宽度。存储不可用时继续保留本次交互。窄屏使用同一面板内容和 Dialog 焦点管理。实现依据：[React ViewTransition](https://react.dev/reference/react/ViewTransition)、[布局开销](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing)。

联系人栏向左拖过收起阈值后，变为 96px 图标栏。头像入口使用联系人高度令牌，显示为居中的圆角正方形。选中底色使用 surface，悬停底色使用 hover，与搜索、新建按钮共用主题颜色。头像、搜索、新建和底部操作继续使用同一组件。向右拖动、双击分隔线或使用方向键可展开。搜索图标展开联系人栏并聚焦搜索。展开宽度与收起状态分别保存。收起和展开遵循减少动态效果设置。窄屏抽屉保持完整联系人列表。

详情首页按打开时读取能力摘要。编辑页保持实时订阅。切换到 Computer、Browser、Work 或关闭详情会暂停工作资料订阅。已编辑的表单保留在内存中。HTTP/1 下两个默认打开的首页不应占满连接并阻塞普通请求，参见 [MDN 连接限制](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events/Using_server-sent_events)。切换 Bot 或刷新页面会重建详情。聊天草稿沿用原持久化机制。全局设置切换分类保留表单；关闭时检查未保存的模型配置，并等待正在执行的请求。

Harness 状态、模型目录和思考选项由每个 Bot 的共享状态持有。切换侧栏立即显示已有信息，后台检查完成后再更新。模型选择立即更新显示并关闭菜单。保存按序执行。思考选项继续可用。发送任务前等待保存完成。失败时恢复已确认的选择，并显示错误。

聊天历史每页最多 200 条。实时连接只发送变化的消息和运行字段。工具正文和内嵌图片按需读取。翻页保留阅读位置。实时更新和重新连接保留已加载的历史。Work 弹窗按需补齐跨页记录。

创建时间为目录的可选字段，与现有文档版本兼容。旧代码继续读取其他字段。权限校验和执行目标仍由后端决定。

Work 每次完整执行显示一张卡片。追加输入归入原执行。卡片显示原生当前活动、模型、耗时、最近五项记录和 Stop。有原生计划时显示分段进度。点击卡片或 Open run 打开共享 Dialog。弹窗实时展示原生过程、工具参数、结果和证据。停止按钮与输入框调用同一接口。历史状态从现有持久记录恢复。
