# 消息交付与阅读

状态：已采用。

聊天投影按任务区分工作过程与正式回复。运行中的正文、过程消息和生成文件保留在任务中。任务完成后，正文与文件一起进入聊天。标记为 question 的产品消息与引擎审批立即显示。旧记录中未标记用途的产品消息按 update 处理。

停止和失败保留已保存的草稿与文件记录。引擎任务保存终止状态及失败原因。重试入口将原任务放回输入框，由用户发送。

订阅更新按浏览器帧合并。历史消息保留稳定引用。Markdown 使用缓存。收起的操作详情按需挂载。历史首屏显示最近 120 项，查看更早内容时最多挂载 240 项。

短回复贴底。长回复对齐开头。用户翻看历史时保留位置，并显示新消息提示。历史分页保留可见消息的位置。跳到最新后恢复跟随。

新回复使用一次位置与透明度动画。初次加载、重新打开和后台到达的消息直接显示。系统要求减少动画时，关闭入场与工作头像动画。
