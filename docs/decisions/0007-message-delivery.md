# 消息交付与阅读

状态：已采用。

聊天投影按引擎的消息完成事件交付正文。每条完整消息立即进入聊天，任务可以继续工作。逐字草稿、思考和工具记录不显示。产品消息、问题与引擎审批立即显示。生成文件在任务完成后交付。

等待期间，在最新消息下方显示三个 SVG 圆点。圆点使用 Bot 头像主题色，依次变亮和放大。输入框上方不显示工作头像和状态文字，聊天内不提供执行过程展开入口。

停止和失败保留已交付的完整消息。未完成草稿和文件记录保留在任务中。聊天只显示简短结果提示和重试入口。重试将原任务放回输入框，由用户发送。提前停止时，根据持久任务的中止结果保存提示。

订阅更新按浏览器帧合并。历史消息保留稳定引用。Markdown 使用缓存。历史首屏显示最近 120 项，查看更早内容时最多挂载 240 项。

短回复贴底。长回复对齐开头。用户翻看历史时保留位置，并显示新消息提示。历史分页保留可见消息的位置。跳到最新后恢复跟随。

新回复使用一次位置与透明度动画。初次加载、重新打开和后台到达的消息直接显示。三点循环只改变缩放与透明度。系统要求减少动画时，关闭入场和圆点动画。
