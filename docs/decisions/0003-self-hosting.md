# 自托管实例与工作电脑

状态：已采用。

桌面连接实例。实例配置工作电脑。普通客户端不配置沙箱运行时。产品边界为单所有者、多设备。

Pi 管理模型、工具协议、执行和恢复。托管模块管理安装、设备身份、凭据持久化和备份。API 统一实施设备权限。桌面只向可信安装页开放固定 IPC。

控制端独占 Docker 管理能力。API 使用固定生命周期操作和已鉴权的 Pi 字节流。工作电脑不获取服务凭据或 Docker socket。共享电脑的 Bot 共享权限。

网络分别声明断网、HTTP(S) 代理出网和 Linux 防火墙受限出网。能力来自运行状态。核验失败则拒绝连接。

更新采用停写、备份、安装、验证流程。恢复创建新工作卷。备份使用标准归档和认证加密，还原前完成认证校验。

桌面分发使用可移植生产依赖树。测试校验依赖路径，并启动包内后台。公开发行前配置代码签名。

其他后端须完成生命周期、Pi 执行协议和文件接入，并通过同一行为套件。未验收后端不进入产品选项。
