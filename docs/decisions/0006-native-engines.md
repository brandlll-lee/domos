# Domos 主脑与产品边界

状态：已采用。

Pi Durable 1.4.0 是唯一 Bot 主循环。Pi AI 负责模型调用。Domos 负责身份、完整消息记录、记忆、技能、定时任务、账号和工作电脑。集成使用上游 extensions、hooks 和工具接口。

普通消息、连续追加和定时任务使用同一 Conversation.submit 入口。requestId 标识一次提交。Durable 原生 inbox 区分追加指令与下一轮输入。GenerationTask 和 ToolTask 负责执行、取消和恢复。上下文压缩不删除界面历史。

模型配置沿用 Hosting 的账号与模型服务。模型在 Domos 服务端调用。命令、文件、Browser Use 和 CUA 在 Bot 绑定的工作电脑执行。服务电脑与工作电脑可以不同。

共享电脑工具保留输入验证、审批、用户接管、取消和证据存储。工具身份绑定当前 Bot。电脑工具按顺序执行。变更动作不声明可重放。重启后失效的审批与接管不能执行。已投递但结果不明的操作须先核对。

旧消息、附件、记忆和原生会话文件保留。迁移结算旧任务并保存未完成展示内容。近期历史以有字节预算的引用数据进入模型上下文。conversation_read 提供完整历史读取。

打开旧 SQLite schema 前，Domos 使用 SQLite backup 创建 .v1-backup。随后由上游迁移数据库。回滚必须停止服务，保存当前数据，再恢复匹配旧程序的备份。旧程序不能继续写新版数据库。

首次设置依次选择工作电脑和模型。各客户端共享模型选择和审批状态。外部 coding runner 与群聊不属于当前运行时接口。
